# brainforwarding/homebrew-tap

Homebrew casks for [Iliad MD](https://iliad.md), a calm Markdown writing app for Mac.

```sh
brew install --cask brainforwarding/tap/iliad-md
```

This installs `Iliad MD.app` and links the `iliad` command. Update with `brew upgrade --cask iliad-md`.

The cask source of truth lives in the app repo at
[`packaging/homebrew/iliad-md.rb`](https://github.com/brainforwarding/iliad/blob/master/packaging/homebrew/iliad-md.rb)
and is copied here on each release.
